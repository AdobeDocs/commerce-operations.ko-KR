# ACP2E-5027: 응용 프로그램 잠금이 파일 잠금 공급자를 사용할 때 인덱서가 완료되지 않음

ACP2E-5027 패치는 `use_application_lock`이(가) 사용되고 파일 잠금 공급자가 구성된 경우 인덱서가 자체 잠금을 계속 획득하려고 하므로 인덱서가 끝나지 않는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-5027입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정될 예정입니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.9

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.4 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

`use_application_lock`이(가) 사용되고 파일 잠금 공급자가 구성된 경우 자체 잠금을 계속 가져오려고 하므로 인덱서가 끝나지 않습니다.

<u>재현 단계</u>:

1. `app/etc/env.php`에서 인덱서에 대해 응용 프로그램 잠금을 사용하도록 설정하고 잠금 공급자를 파일로 설정합니다.

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. `catalog_product_category` 인덱서 실행:

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>예상 결과</u>:

`catalog_product_category` 다시 인덱싱이 완료되었습니다.

<u>실제 결과</u>:

색인 재지정이 완료되지 않습니다.
