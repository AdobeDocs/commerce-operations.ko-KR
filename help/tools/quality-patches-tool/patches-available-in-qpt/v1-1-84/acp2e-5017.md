# ACP2E-5017: 회사가 없는 고객에 대한 GraphQL 고객 역할 쿼리가 실패합니다

ACP2E-5017 패치는 GraphQL `customer` 쿼리의 `role` 필드가 회사에 할당되지 않은 고객에 대해 *내부 서버 오류*&#x200B;를 반환하는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-5017입니다. 이 문제는 Adobe Commerce B2B 1.5.4에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) B2B 1.5.3

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

GraphQL `customer` 쿼리의 `role` 필드에서 회사에 할당되지 않은 고객에 대해 *내부 서버 오류*&#x200B;을 반환합니다.

<u>필수 구성 요소</u>:

B2B가 설치되었습니다.

<u>재현 단계</u>:

1. 관리자에서 **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**(으)로 이동하고 **[!UICONTROL Enable Company]**&#x200B;을(를) *[!UICONTROL Yes]*(으)로 설정한 다음 **[!UICONTROL Save Config]**&#x200B;을(를) 클릭합니다.
1. 회사에 할당되지 않은 고객 계정을 만듭니다.
1. 유효한 고객 토큰을 사용하여 다음 GraphQL 쿼리를 보냅니다.

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>예상 결과</u>:

쿼리에서 `role`이(가) *null*(으)로 설정된 고객 데이터를 오류 없이 반환합니다.

<u>실제 결과</u>:

쿼리가 *내부 서버 오류*&#x200B;을(를) 반환합니다.
