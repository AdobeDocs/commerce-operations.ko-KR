# AC-15494: GraphQL 제품 쿼리가 HTML 이스케이프 처리된 제품 이름을 반환합니다.

AC-15494 패치는 `products` 쿼리가 원본 문자 대신 HTML 이스케이프 처리된 특수 문자로 제품 이름을 반환하는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 AC-15494입니다. 이 문제는 Adobe Commerce 2.4.9에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8-p5

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

`products` 쿼리는 원래 문자 대신 HTML 이스케이프 처리된 특수 문자를 사용하여 제품 이름을 반환합니다.

<u>재현 단계</u>:

1. SKU `testsku`을(를) 사용하여 이름이 `55" 4K UHD Smart TV`인 새 제품을 만드십시오.
1. 다음 GraphQL 쿼리를 제출합니다.

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>예상 결과</u>:

`products` 쿼리가 저장된 제품 이름을 원래 큰따옴표로 반환합니다.

<u>실제 결과</u>:

반환된 제품 이름에 원래 문자 대신 HTML 이스케이프 처리된 큰따옴표가 있습니다.
