# ACP2E-5122: 처리된 GraphQL 장바구니 오류가 예외 로그에 잘못 기록됨

ACP2E-5122 패치는 처리된 GraphQL 장바구니 요청 오류가 예외 로그에 애플리케이션 오류로 기록되는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-5122입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8-p5

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.4 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

처리된 GraphQL 장바구니 요청 오류는 애플리케이션 오류로 예외 로그에 기록됩니다.

<u>재현 단계</u>:

1. 이 돌연변이와 같이 잘못되었거나, 만료되었거나, 이미 파괴된 마스킹된 장바구니 ID가 있는 GraphQL `placeOrder` 돌연변이를 보냅니다.

   ```
       mutation {
           placeOrder(input: { cart_id: "test" }) {
               orderV2 {
                   id
                   number
               }
           }
       }
   ```

1. GraphQL 응답을 확인합니다.
1. 장바구니 오류에 대해 `var/log/exception.log`을(를) 확인하십시오.

<u>예상 결과</u>:

1. GraphQL 요청이 *HTTP 500* 응답 없이 잘못된 장바구니에 대해 처리된 클라이언트측 오류 페이로드를 반환합니다.
1. 처리된 *GraphQlNoSuchEntityException*&#x200B;이(가) `var/log/exception.log`에 기록되지 않고 대신 낮은 심각도 로그 채널로 라우팅됩니다.

<u>실제 결과</u>:

각 요청은 `var/log/exception.log`에 `report.ERROR` 심각도로 처리된 예외를 기록하며, 이로 인해 반복된 요청 동안 제한 없는 로그 증가가 발생합니다.
