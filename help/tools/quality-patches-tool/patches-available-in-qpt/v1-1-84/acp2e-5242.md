# ACP2E-5242: GraphQL은 장바구니 추가 요청 동안 스토어 ID를 웹 사이트 ID로 사용합니다

ACP2E-5242 패치는 장바구니에 항목을 추가하는 동안 제품 가용성을 확인하는 경우 웹 사이트를 찾을 수 없음을 나타내는 오류가 표시되는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-5242입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.9

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

장바구니에 항목을 추가하는 동안 제품 가용성을 확인하면 웹 사이트를 찾을 수 없음을 나타내는 오류가 표시됩니다.

<u>재현 단계</u>:

1. 관리자 패널에 로그인합니다.
1. **관리자** > **[!UICONTROL Stores]** > **설정** > **[!UICONTROL All Stores]**(으)로 이동하여 **[!UICONTROL Create Store View]**&#x200B;을(를) 클릭합니다.
1. 예를 들어 &quot;store_2&quot;라는 두 번째 스토어 뷰를 만듭니다.
1. &quot;Store: store2&quot; HTTP 헤더를 사용하여 GraphQL 요청으로 빈 게스트 카트를 만듭니다.
1. 반환된 장바구니 ID를 기록합니다.
1. &quot;Store: store2&quot; HTTP 헤더, 제품 SKU 및 장바구니 ID를 사용하여 GraphQL 요청이 있는 장바구니에 간단한 제품을 추가합니다.

<u>예상 결과</u>:

제품이 GraphQL 요청을 통해 장바구니에 정상적으로 추가되었습니다.

<u>실제 결과</u>:

GraphQL 요청이 실패하고 &quot;요청한 ID를 가진 웹 사이트를 찾을 수 없습니다...&quot;라는 메시지가 기록됩니다. 웹 사이트를 확인하고 다시 시도하십시오.&quot; var/log/exception.log으로 이동합니다.
