# ACP2E-5183: PHP 8.5에서 `@magento_import`을(를) 사용하여 정적 콘텐츠 배포가 실패합니다.

ACP2E-5183 패치는 모듈 `LESS` 파일에서 `@magento_import` 지시문을 사용할 때 PHP 8.5에서 *배열 오프셋으로 null을 사용하는 것은 더 이상 사용되지 않습니다* 오류와 함께 정적 콘텐츠 배포가 실패하는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-5183입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.9

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.4 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

모듈 `LESS` 파일에서 `@magento_import` 지시문을 사용하는 경우 *배열 오프셋으로 null을 사용하는 방법은 더 이상 사용되지 않습니다* 오류가 발생하여 PHP 8.5에서 정적 콘텐츠 배포가 실패합니다.

<u>필수 구성 요소</u>:

PHP 8.5가 설치되어 있습니다.

<u>재현 단계</u>:

1. 사용자 지정 전자 메일 본문 스타일과 `@magento_import` 지시문이 포함된 `email-inline.less` 파일을 제공하는 사용자 지정 모듈을 사용하도록 설정합니다.
1. 정적 콘텐츠 및 생성된 파일 제거:

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. 컴팩트 전략을 사용하여 정적 컨텐츠 배포를 실행합니다.

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>예상 결과</u>:

정적 콘텐츠 배포가 성공적으로 완료되고 모듈에서 제공한 `LESS` 파일에 대해 컴파일된 CSS가 생성됩니다.

<u>실제 결과</u>:

모듈에서 제공한 `email-inline.less` 파일 및 보고서를 컴파일하는 동안 정적 콘텐츠 배포가 중단됩니다.

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
