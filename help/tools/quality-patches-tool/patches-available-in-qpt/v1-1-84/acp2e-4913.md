# ACP2E-4913: 데이터베이스 교착 상태 후 REST API 선적 및 송장 생성이 재시도되지 않음

ACP2E-4913 패치는 데이터베이스 교착 상태가 발생할 때 작업을 다시 시도하지 않아 REST API를 통해 선적 또는 송장을 만들 수 없는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4913입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8-p3

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

REST API를 통해 선적 또는 송장을 만드는 경우 데이터베이스 교착 상태가 발생하면 작업이 재시도되지 않으므로 영구적으로 실패합니다.

<u>재현 단계</u>:

1. 선적할 수 있는 몇 개의 주문과 인보이스 발행할 수 있는 몇 개의 주문을 준비합니다.
1. 통합이 로드될 수 있으므로 이러한 주문에 대해 여러 `POST /rest/V1/order/<orderId>/ship` 요청을 동시에 보냅니다.
1. 같은 방법으로 여러 개의 `POST /rest/V1/order/<orderId>/invoice` 요청을 동시에 보냅니다.
1. API 응답 및 `var/log/exception.log`을(를) 확인합니다.

<u>예상 결과</u>:

교착 상태가 발생한 후 작업을 재시도하고 선적 또는 송장을 작성합니다.

<u>실제 결과</u>:

일부 요청이 실패하고 다음 교착 상태 오류가 발생합니다. 선적 또는 송장은 생성되지 않으며 수동으로 생성해야 합니다.

```
SQLSTATE[40001]: Serialization failure: 1213 Deadlock found when trying to get lock; try restarting transaction
```
