# ACP2E-5071: 구매자의 장바구니에 전체 가용 수량이 포함되어 있을 때 재고 비가용성 메시지가 항상 제품 페이지에 표시되는 것은 아닙니다

ACP2E-5071 패치는 구매자 장바구니에 이미 사용 가능한 전체 수량이 포함되어 있을 때 재고 비가용성 메시지가 제품 페이지에 항상 표시되지 않는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86이 설치된 경우에 사용할 수 있습니다. 패치 ID는 ACP2E-5071입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.7 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

구매자 장바구니에 이미 사용 가능한 전체 수량이 포함되어 있는 경우 재고 비가용성 메시지가 제품 페이지에 항상 표시되는 것은 아닙니다.

<u>필수 구성 요소</u>:

전체 페이지 캐시가 활성화되었습니다(내장, 바니시 또는 Fastly).

<u>재현 단계</u>:

1. 관리 패널에서 **카탈로그** > **제품**(으)로 이동하여 간단한 제품(**제품 추가** > **간단한 제품**)을 만들거나 기존 제품을 엽니다.
1. 수량을 2로 설정하고 재고 상태를 재고 상태로 설정한 다음 저장을 누릅니다. 여러 개의 재고 출처가 있는 경우, 대신에 출처 섹션에서 지정된 출처에 대해 수량을 2로 설정합니다.
1. 개인 브라우저 창의 게스트로, Storefront에서 제품 페이지를 열고 한 번 다시 로드하여 전체 페이지 캐시에서 제공합니다.
1. 수량을 2로 설정하고 **[!UICONTROL Add to Cart]**&#x200B;을(를) 클릭합니다.
1. 문제를 더 쉽게 재현할 수 있도록 브라우저 개발자 도구를 열고 성능 패널에서 CPU 스로틀링을 6배 느림으로 설정합니다.
1. 수량을 1로 설정하고 **[!UICONTROL Add to Cart]**&#x200B;을(를) 클릭합니다. 페이지가 다시 로드되어 재고 오류 메시지가 표시됩니다(예: 판매할 항목이 충분하지 않음).
1. **[!UICONTROL Add to Cart]**&#x200B;을(를) 최대 수십 번 다시 클릭하고 클릭할 때마다 페이지가 다시 로드되도록 합니다.

<u>예상 결과</u>:

1. 장바구니에 추가 시도가 실패할 때마다 재고 오류 메시지가 표시됩니다.

<u>실제 결과</u>:

1. 몇 번 시도하면 오류 메시지가 표시되지 않고 페이지가 다시 로드됩니다.
