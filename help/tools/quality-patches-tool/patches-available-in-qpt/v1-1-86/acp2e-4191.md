# ACP2E-4191: EAV 유형 및 속성 캐시가 비활성화될 때 REST API 요청이 무한 루프를 시작합니다

ACP2E-4191 패치는 EAV 유형 및 속성 캐시가 비활성화될 때 특정 REST API 요청이 무한 루프를 입력하는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86이 설치된 경우에 사용할 수 있습니다. 패치 ID는 ACP2E-4191입니다. 이 문제는 Adobe Commerce 2.4.9에서 해결되었습니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.7-p9, 2.4.8-p2

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

EAV 유형 및 속성 캐시가 비활성화되면 특정 REST API 요청이 무한 루프에 들어갑니다.

<u>필수 구성 요소</u>:

Adobe Commerce [!DNL B2B] 확장.

<u>재현 단계</u>:

1. 고객 계정을 만들고 Storefront에 로그인합니다.
1. 장바구니에 제품을 추가하고 체크아웃 페이지를 엽니다.
1. 브라우저 개발자 도구에서 네트워크 탭을 열고 `rest/default/V1/carts/mine/estimate-shipping-methods`과(와) 같은 REST 요청을 검사합니다.
1. EAV 유형 및 속성 캐시를 비활성화합니다.

   ```
   bin/magento cache:disable eav
   ```

1. 체크아웃 페이지를 새로 고치고 동일한 REST 요청을 검사합니다.

<u>예상 결과</u>:

1. 무한 루프를 입력하지 않고 체크아웃 REST 요청이 완료되었습니다.

<u>실제 결과</u>:

1. 무한 루프가 PHP 호출 스택 크기 또는 메모리 제한에 도달하므로 REST 요청은 HTTP 500 오류와 함께 실패합니다.
