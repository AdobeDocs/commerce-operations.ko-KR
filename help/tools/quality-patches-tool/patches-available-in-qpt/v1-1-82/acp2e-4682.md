# ACP2E-4682: `isActive` 견적을 확인하는 저장소 전면 페이지에서 빈 견적 레코드를 만듭니다.

ACP2E-4682 패치는 견적 `isActive` 상태를 확인하는 상점 페이지를 방문하여 페이지를 로드할 때마다 빈 견적 레코드를 만드는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4682입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.7-p8

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.5 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

견적 `isActive` 상태를 확인하는 상점 첫 페이지를 방문하면 페이지가 로드될 때마다 빈 견적 레코드가 만들어집니다.

<u>재현 단계:</u>

1. Storefront 제품 페이지를 사용자 지정하고 견적의 `isActive` 상태를 확인하는 블록을 추가하십시오.
1. 고객 계정에 로그인.
1. 상점 첫 화면에서 제품 페이지를 다시 로드합니다.
1. 다음 쿼리를 실행합니다.

   ```
   SELECT COUNT(*) FROM quote;
   ```

1. 제품 페이지가 로드될 때마다 견적 수가 증가하는지 확인하십시오.

<u>예상 결과:</u>

1. 페이지가 로드될 때 빈 따옴표 레코드가 생성되지 않습니다.

<u>실제 결과:</u>

1. `isActive` 견적 확인이 포함된 페이지를 방문할 때마다 빈 견적 레코드가 만들어집니다.
