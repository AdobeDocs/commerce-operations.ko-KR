# ACP2E-4799: GraphQL 쿼리 `requisition_lists`이(가) 페이지 매김과 함께 잘못된 `total_count`을(를) 반환합니다.

ACP2E-4799 패치는 `requisition_lists` GraphQL 쿼리가 쿼리 기준과 일치하는 총 구매요청 목록 엔티티 수 대신 현재 페이지의 항목 수만 반영하는 잘못된 `total_count` 값을 반환하는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4799입니다. 이 문제는 Adobe Commerce B2B 1.5.4에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) B2B 1.5.2-p4

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) B2B >=1.5.0 &lt;1.5.3

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

고객이 페이지 매김을 사용하여 구매요청 목록을 쿼리할 때 `total_count` 필드에 일치하는 구매요청 목록의 전체 수가 반영되지 않습니다. 대신 현재 페이지에 대해 반환되는 항목 수만 보고하므로 페이지 매김 메타데이터가 부정확합니다.

<u>필수 구성 요소</u>:

Adobe Commerce B2B에 대해 구매요청 목록을 사용할 수 있습니다.

<u>재현 단계</u>:

1. 관리자에서 **[!UICONTROL Stores]** > **설정** > **구성**(으)로 이동합니다.
1. **일반** 아래의 왼쪽 패널에서 **B2B 기능**&#x200B;을 선택합니다.
1. **[!UICONTROL Enable Requisition List]**&#x200B;을(를) **[!UICONTROL Yes]**(으)로 설정하고 **[!UICONTROL Save Config]**&#x200B;을(를) 선택합니다.
1. 상점에 고객으로 로그인합니다.
1. **[!UICONTROL My Requisition Lists]**&#x200B;을(를) 선택하고 6개의 요청 목록을 만듭니다.
1. 고객에게 정확히 6개의 구매요청 목록이 있고 각 목록 이름에 `ABC`이(가) 포함되어 있는지 확인하여 6개의 목록이 모두 필터링된 쿼리와 일치하는지 확인하십시오.
1. `pageSize`을(를) 2로 설정하고 `currentPage`을(를) 1로 설정하여 다음 GraphQL 쿼리를 실행합니다.

   ```graphql
   query {
     customer {
       requisition_lists(
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```

1. 이 GraphQL 쿼리 실행:

   ```graphql
   query {
     customer {
       requisition_lists(
         filter: { name: { match: "%ABC%" } }
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```


<u>예상 결과</u>:

* `requisition_lists` 쿼리는 `pageSize` 및 `currentPage`에 관계 없이 고객이 소유한 총 구매요청 목록 수와 같은 `total_count`을(를) 반환합니다.
* 페이지 매김 데이터는 전체 일치 결과 세트와 일관성을 유지합니다.

<u>실제 결과</u>:

`total_count`은(는) 현재 페이지의 항목 수만 반환합니다(예: 6개가 아닌 2개).
