# ACP2E-4593: 잘못된 웹 사이트 제한 CMS 페이지가 다중 웹 사이트 상점 첫 화면의 보조 웹 사이트에서 제공됩니다

ACP2E-4593 패치는 랜딩 페이지 캐시 키가 웹 사이트별로 범위가 지정되지 않으므로 다중 웹 사이트 설정의 보조 웹 사이트 상점 첫 페이지에 잘못된 웹 사이트 제한 사항 CMS 페이지가 제공되는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4593입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.5-p15

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.5 - 2.4.9

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

잘못된 웹 사이트 제한 CMS 페이지는 웹 사이트별로 랜딩 페이지 캐시 키의 범위가 지정되지 않기 때문에 다중 웹 사이트 설정의 보조 웹 사이트 상점 앞에 제공됩니다.

<u>필수 구성 요소</u>:

인벤토리가 설치되었습니다.

<u>재현 단계</u>:

1. 두 개의 웹 사이트를 만듭니다.
1. 두 개의 CMS 페이지를 만들고, 컨텐츠 섹션의 각 페이지에 다른 텍스트를 추가하고, 각 페이지를 다른 웹 사이트에 할당합니다.
1. 웹 사이트 제한을 활성화하고 해당 웹 사이트에 대한 랜딩 페이지를 구성합니다.
1. 캐싱이 활성화되어 있는지 확인합니다.
1. 첫 번째 웹 사이트에 대한 상점 첫 페이지를 열고 표시된 랜딩 페이지 콘텐츠를 확인합니다.
1. 두 번째 웹 사이트에 대한 스토어를 열고 첫 번째 웹 사이트의 랜딩 페이지 콘텐츠가 여전히 표시되는지 확인합니다.

<u>예상 결과</u>:

각 웹 사이트는 상점 첫 화면에 각각의 CMS 페이지를 올바르게 표시합니다.

<u>실제 결과</u>:

두 웹 사이트 모두 처음 액세스한 페이지인 동일한 CMS 페이지를 표시합니다.
