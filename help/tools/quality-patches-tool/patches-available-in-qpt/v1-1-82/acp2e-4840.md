# ACP2E-4840: GraphQL 제품 쿼리가 사용자 정의 재고 재고의 재고 제품에 대해 null 수량을 반환합니다.

ACP2E-4840 패치는 제품 GraphQL 쿼리의 수량 필드가 재고에 있고 사용자 정의 재고 재고에서 판매할 수 있는 제품에 대해 null을 반환하는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4840입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8-p4

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

제품 GraphQL 쿼리의 수량 필드는 재고가 있고 사용자 정의 재고 재고에서 판매할 수 있는 제품에 대해 null을 반환합니다.

<u>필수 구성 요소</u>:

MSI가 활성화되었습니다.

<u>재현 단계</u>:

1. 새 소스를 만듭니다.
1. 관리 사이드바에서 **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**(으)로 이동합니다.
1. **[!UICONTROL Add New Stock]**&#x200B;을(를) 클릭합니다.
1. **[!UICONTROL Sales Channels]**&#x200B;을(를) 확장하고 재고를 사용할 수 있는 **[!UICONTROL Websites]**&#x200B;을(를) 선택합니다.
1. **[!UICONTROL Sources]**&#x200B;을(를) 확장하고 **[!UICONTROL Assign Sources]**&#x200B;을(를) 클릭한 다음 할당할 원본을 선택하고 **[!UICONTROL Done]**&#x200B;을(를) 클릭합니다.
1. 관리 사이드바에서 **[!UICONTROL Catalog]** > **[!UICONTROL Products]**(으)로 이동하여 기존 제품을 편집 모드로 엽니다.
1. **[!UICONTROL Sources]** 섹션에서 사용자 지정 소스를 할당하고 **[!UICONTROL Source Item Status]**&#x200B;을(를) **[!UICONTROL In Stock]**(으)로 설정하고 **[!UICONTROL Qty]**&#x200B;에 대해 0이 아닌 값을 입력한 다음 제품을 저장합니다.
1. **[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;에서 사용자 지정 스톡에 할당된 웹 사이트에 대해 제품에 0이 아닌 **[!UICONTROL Salable Quantity]**&#x200B;이(가) 표시되는지 확인합니다.
1. 사용자 지정 스톡을 사용하는 웹 사이트에 할당된 스토어 보기에 대해 해당 SKU에 대해 다음 `products` [!DNL GraphQL] 쿼리를 실행합니다.

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. 응답을 확인합니다.

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>예상 결과</u>:

GraphQL 응답은 현재 스토어/웹 사이트에서 재고 및 판매 가능한 제품에 대해 null이 아닌 수량 값을 반환합니다.

<u>실제 결과</u>:

스토어에서 사용자 지정 MSI 스톡을 사용할 때 관리자에서 재고 및 판매 가능한 제품에 대해 `stock_status` = `IN_STOCK`인 동안 GraphQL 응답이 `quantity = null`을(를) 반환합니다.
