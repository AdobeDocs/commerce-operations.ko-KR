# ACP2E-4194: 알 수 없는 필터 이름을 가진 GraphQL 요청으로 인해 PHP 예외 로그가 발생합니다

ACP2E-4194 패치는 알 수 없는 필터 이름을 가진 GraphQL 요청이 PHP 예외 로그를 초래하는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82가 설치되어 있을 때 사용할 수 있습니다. 패치 ID는 ACP2E-4194입니다. 이 문제는 Adobe Commerce 2.4.9에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.7-p10, 2.4.8-p5

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) 2.4.7-p10, 2.4.8-p5

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

알 수 없는 필터 이름을 가진 GraphQL 요청으로 인해 PHP 예외 로그가 발생하는 문제가 발생했습니다.

<u>재현 단계</u>:

알 수 없거나 잘못된 필터 이름이 있는 GraphQL 요청 보내기:

```
query Test($filter: FindFilterType){ cmsBlocks(identifiers:["home"]) { items { title } } }
```

<u>예상 결과</u>:

요청을 구문 분석할 수 없거나, 요청이 승인되지 않았거나, 요청에 다른 일반적인 문제가 있는 경우 4XX 응답 코드가 반환됩니다. 요청을 구문 분석하고 처리할 수 있는 경우 *200* 응답 코드가 반환됩니다.

<u>실제 결과</u>:

내부 서버 오류가 응답에 반환되고 `exception.log`에서 다음 오류가 발생합니다.

```
report.CRITICAL: LogicException: Config element "FindFilterType" is not declared in GraphQL schema in /var/lib/internal/Magento/Framework/GraphQl/Config.php:57
```
