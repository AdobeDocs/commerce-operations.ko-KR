# AC-18128: 영어 이외의 로케일에 대한 GraphQL 주문 날짜 및 댓글 타임스탬프가 올바르지 않음

AC-18128 패치는 GraphQL에서 반환한 주문 날짜 및 주문 설명 타임스탬프가 영어가 아닌 로케일 설정에서 잘못된 캘린더 날짜를 표시할 수 있는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83이 설치된 경우에 사용할 수 있습니다. 패치 ID는 AC-18128입니다. 이 문제는 Adobe Commerce 2.4.8에서 해결되었습니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.8

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) >=2.4.8 &lt;2.4.8-p6

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

GraphQL에서 반환한 주문 날짜 및 주문 설명 타임스탬프에 영어가 아닌 로케일 설정에서 잘못된 캘린더 날짜가 표시될 수 있습니다.

<u>재현 단계</u>:

1. 관리 패널에서 **[!UICONTROL Stores]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL Locale Options]**(으)로 이동합니다. **[!UICONTROL Timezone]**&#x200B;을(를) *유럽/파리*(으)로 설정합니다. **[!UICONTROL Locale]**&#x200B;을(를) *프랑스어(프랑스)*(으)로 설정합니다. 구성을 저장합니다.
1. 가게 앞에 가서 주문하세요.
1. 다음 Customer Orders GraphQL 쿼리를 실행합니다.

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>예상 결과</u>:

GraphQL 응답의 주문 날짜 및 주석 타임스탬프는 스토어 로케일에 관계없이 올바른 캘린더 날짜를 반영합니다.

<u>실제 결과</u>:

`fr_FR` 및 `de_DE`과(와) 같이 `en_US`이(가) 아닌 로케일의 경우 날짜 구문 분석 문제로 인해 `order_date`에 잘못된 일정 날짜가 표시됩니다.
