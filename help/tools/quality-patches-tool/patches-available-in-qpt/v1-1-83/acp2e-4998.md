# ACP2E-4998: SKU 누락으로 인해 유효한 제품에 대한 벌크 계층 가격 업데이트가 방지됨

ACP2E-4998 패치는 페이로드의 한 SKU가 존재하지 않아 유효한 SKU가 업데이트되지 않는 경우 `POST /V1/products/tier-prices` REST API 요청이 완전히 실패하는 문제를 수정합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83이 설치된 경우에 사용할 수 있습니다. 패치 ID는 ACP2E-4998입니다. 이 문제는 Adobe Commerce 2.4.10에서 수정됩니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.7 - p10

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

페이로드의 SKU 하나가 없는 경우 `POST /V1/products/tier-prices` REST API 요청이 완전히 실패하여 유효한 SKU가 업데이트되지 않았습니다.

<u>재현 단계</u>:

1. 기존 제품 SKU(예: `product_dynamic_1`)와 카탈로그에 없는 SKU(예: `product_dynamic_001`)를 식별합니다.
1. 동일한 페이로드에 두 SKU가 모두 포함된 `/rest/V1/products/tier-prices`에 POST 요청을 제출합니다.

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>예상 결과</u>:

1. 계층 가격은 기존 SKU에 대해 저장됩니다.
1. 응답이 누락된 SKU를 항목 수준 오류로 보고합니다.

<u>실제 결과</u>:

1. *SKU가 &quot;%1&quot;인 제품이 없습니다.* 오류가 발생하여 요청이 실패합니다. 대상: `product_dynamic_001`
1. 기존 SKU에 대해 저장된 계층 가격이 없습니다.
