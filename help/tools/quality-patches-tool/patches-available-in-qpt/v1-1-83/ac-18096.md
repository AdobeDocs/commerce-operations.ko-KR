# AC-18096: Sales GraphQL 날짜 필드에서 잘못된 지역화된 형식을 반환함

AC-18096 패치는 날짜 형식을 슬래시로 구분된 `/`에서 대시로 구분된 `-`(으)로 되돌려 Sales GraphQL 날짜 필드가 이전 릴리스와 다른 형식으로 날짜를 반환하는 문제를 해결합니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83이 설치된 경우에 사용할 수 있습니다. 패치 ID는 AC-18096입니다. 이 문제는 Adobe Commerce 2.4.9에서 해결되었습니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) 2.4.9

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) >2.4.8 &lt;=2.4.9-p1

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

Sales GraphQL 날짜 필드는 Adobe Commerce 2.4.8에서 사용되는 대시 구분 형식 `(Y-m-d H:i:s)` 대신 슬래시로 구분된 형식 `(d/m/Y H:i:s)`의 날짜 및 시간 값을 반환합니다

<u>필수 구성 요소</u>:

- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Timezone]**: *유럽/파리*
- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Locale]**: *프랑스어(프랑스)*

<u>재현 단계</u>:

1. 주문을 만듭니다.
1. GraphQL을 사용하여 주문 날짜 세부 사항 검색:

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>예상 결과</u>:

- 이 필드는 버전 2.4.8의 출력과 일치하는 `Y-m-d H:i:s`의 값을 반환합니다.

<u>실제 결과</u>:

- 필드가 `2026-08-27 14:12:55`과(와) 같은 `Y-m-d H:i:s` 대신 `27/08/2026 14:12:55`과(와) 같은 `d/m/Y H:i:s`의 값을 반환합니다.
