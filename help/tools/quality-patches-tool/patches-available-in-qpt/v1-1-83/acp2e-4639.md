# ACP2E-4639: Adobe Commerce GraphQL 스키마의 구매요청 목록 항목 유형

ACP2E-4639 패치는 GraphQL 스키마에서 구매요청 목록 항목 유형의 철자가 잘못된 문제를 수정합니다. 새 `requisition_list_items` 필드는 맞춤법이 올바른 `RequisitionListItems` 형식을 반환하지만, 이전 `items` 필드와 `RequistionListItems` 형식은 계속 사용할 수 있지만 더 이상 사용되지 않습니다. 이 패치는 [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83이 설치된 경우에 사용할 수 있습니다. 패치 ID는 ACP2E-4639입니다. 이 문제는 Adobe Commerce B2B 1.5.3에서 해결되었습니다.

## 영향을 받는 제품 및 버전

**Adobe Commerce 버전에 대한 패치가 만들어졌습니다.**

* Adobe Commerce(모든 배포 방법) B2B 1.5.2 - p1

**Adobe Commerce 버전과 호환:**

* Adobe Commerce(모든 배포 방법) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>새 [!DNL Quality Patches Tool] 릴리스가 있는 다른 버전에 패치를 적용할 수 있습니다. 패치가 Adobe Commerce 버전과 호환되는지 확인하려면 `magento/quality-patches` 패키지를 최신 버전으로 업데이트하고 [[!DNL Quality Patches Tool]에서 호환성을 확인합니다. 패치 검색 페이지](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ko). 패치 ID를 검색 키워드로 사용하여 패치를 찾습니다.

## 문제

GraphQL 스키마에서 구매요청 목록 항목 유형의 철자가 `RequistionListItems`(으)로 잘못 입력되었습니다. 이전 `items` 필드 및 `RequistionListItems` 유형은 계속 사용할 수 있지만 더 이상 사용되지 않습니다.

<u>필수 구성 요소</u>:

B2B 확장이 있는 Adobe Commerce.

<u>재현 단계</u>:

1. 다음 GraphQL 자체 검사 쿼리를 보냅니다.

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. 응답에서 `items` 필드가 반환하는 형식을 확인합니다.

<u>예상 결과</u>:

1. `requisition_list_items` 필드에서 맞춤법이 올바른 `RequisitionListItems` 형식을 반환합니다.
1. `items` 필드 및 `RequistionListItems` 유형은 계속 사용할 수 있으며 더 이상 사용되지 않는 것으로 표시됩니다.

<u>실제 결과</u>:

`items` 필드는 맞춤법이 잘못된 `RequistionListItems` 형식을 반환하고 올바른 맞춤법이 있는 `RequisitionListItems` 형식을 반환하지 않습니다.
