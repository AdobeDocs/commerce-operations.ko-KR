# 피드백 기반 설명서 업데이트

피드백에 대한 응답으로 이러한 설명서를 업데이트했습니다. 각 프로젝트는 소스 목록이 적용되는 기간을 정의합니다.

## Adobe Commerce 서비스 안내서

이러한 업데이트는 [Adobe Commerce 서비스 가이드](https://experienceleague.adobe.com/ko/docs/commerce/user-guides/home) 홈 페이지의 *새로운 기능* 섹션에서 제공됩니다.
